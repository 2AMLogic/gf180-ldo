# Record 20261006-005441-7edf6f2

- **Record ID**: 20261006-005441-7edf6f2
- **Claim**: The precondition under which sim/loop-stability/'s Bode phase and gain margins are a stability test at all: DR-0001's 'PM >= 45 deg and GM >= 10 dB' criterion is only valid when the loop gain T(s) has no right-half-plane poles, i.e. when the forward path is stable with the LDO loop broken. design/error_amp.sch keeps a LOCAL feedback loop (Rz/Cc from N1 around M2P and the class-AB gate buffer back to OUT) closed in exactly that condition, so the precondition is a design property that has to be measured, not assumed. This bench measures it in the time domain, where no phase-unwrapping convention can hide it: with EN held high and the loop settled, the peak-to-peak of the amplifier's internal BG node and of the pass gate over a late, quiet window must be at the noise floor. This bench makes NO claim about the LDO loop's own margins -- that is sim/loop-stability/'s (issue #10's) claim, and it is the claim this one is a precondition for. Update (#174, 2026-09-05, spec/decision-records/DR-0021): ldo_core's VREF was promoted from an internal net -- driven by Vref1, an ideal 1.2 V vsource instantiated INSIDE the subcircuit -- to a seventh top-level port, and the identical ideal source moved into this deck. No device was added, removed or resized, so this is an electrical no-op by construction: an ideal vsource is an ideal vsource wherever it is declared, its return was already the cell's VSS port, and it is an AC short to ground in both placements. It is not asserted on that argument alone -- origin/main at ec9e530 was extracted to a scratch tree and this bench was run on BOTH trees back to back, on the same host with the same ngspice and the same pinned PDK, and the per-corner measurement lines compared field by field; DR-0021's 'Evidence' section tabulates the result. Records minted from this deck before 2026-09-05 carry the pre-#174 six-port DUT netlist sha and are superseded on that ground alone, not because any number in them was wrong; per sim/README.md's append-only rule they are left untouched.

Verified by hand at tt/27C/3.30V -- a 400 ns ceiling reports 37 nV pk-pk on the heavy branch where this setting reports 3.31 V. The coarse setting is the false negative; do not loosen it to make the matrix cheaper.
