# Record 20260905-232555-3093ea1

- **Record ID**: 20260905-232555-3093ea1
- **Supersedes**: none (this is not a correction — it re-runs the same
  testbench topology, unchanged in substance, against the post-#174/DR-0021
  seven-port `ldo_core` netlist; the prior record
  `20260807-105239-64249c6` is not itself in error and is left untouched,
  per `sim/README.md`'s append-only rule)
- **Claim**: `README.md` target-spec **"Enable / shutdown"** row — *shutdown
  Iq < 3 µA at ff / 125 °C / 3.63 V; disabled output state is pass device
  fully off with no internal active discharge; Vin→Vout leakage ≤ 1 µA at the
  same corner*; plus, on the same runs, the **Iq** row's *< 30 µA at full
  load* in the enabled state.
- **Why this re-run exists**: issue #174 / `spec/decision-records/DR-0021` —
  `ldo_core`'s `VREF` was promoted from an internal net (driven by `Vref1`,
  an ideal 1.2 V vsource instantiated INSIDE the subcircuit) to a seventh
  top-level port, and the identical ideal source moved into this deck's
  testbench template (now `Vref`, at deck level). The deck's Iq accounting
  changed **mechanically** with it: `m_iref_en_ua` / `m_iref_off_ua` are now
  metered from `-i(vref)` (the external source's current) instead of an
  internal-node current vector, per `tb_enable_shutdown.spice.in`'s header —
  this is also what makes `m_iref_*_ua` a directly-measured statement of the
  bias current load this block presents at the `VREF` port to whatever
  drives it (e.g. the Chipalooza Challenge #5 bandgap-referenced bias slot),
  which is exactly the contract DR-0021 §3 states a `VREF` driver must meet.
  No device was added, removed or resized in `ldo_core` itself, so the
  electrical result is expected to be a no-op — confirmed below.
- **Netlist provenance**: schematic — `design/netlist/ldo_core.spice`,
  frozen at `netlist-snapshots/20260905-232555-3093ea1.spice` — **taken
  against a dirty working tree** (uncommitted `VREF`-port change staged for
  this same PR); not citable as a clean-tree result independent of this PR.
- **Corner matrix run**: 63 points — process {tt, ff, ss, fs, sf, res_ff,
  res_ss} × T {−40, 27, 125 °C} × Vin {2.97, 3.30, 3.63 V}. Full factorial,
  all completed. `bjt_ff` / `bjt_ss` omitted (no bipolar device).
- **Testbench**: `sim/enable-shutdown/` — topology unchanged from the
  baseline record except for the `VREF` source's relocation described above,
  so every number below is directly comparable, row for row and corner for
  corner.
- **Operating conditions**: unchanged. 50 mA (`Rload` = 36 Ω) for the enabled
  op point and the transient; load removed (1 GΩ) for the settled disabled op
  point; 1 µF / 100 mΩ output; the `VREF` source's current metered separately
  (now via `-i(vref)` at deck level) and added into every quiescent number,
  same as before.

## Result: the ratified rows do not move at all, and that is the point

| Quantity | pre-#174 baseline (`64249c6`) | **this record** | ratified |
|---|---|---|---|
| shutdown Iq @ ff/125 °C/3.63 V | 0.2040 µA | **0.20402 µA** | < 3 µA |
| Vin→Vout leakage @ ff/125 °C/3.63 V | 0.2143 µA | **0.21429 µA** | ≤ 1 µA |
| disabled `VOUT` @ same corner | 0.1796 V | **0.17962 V** | pass device off, no active discharge |
| enabled Iq @ ff/125 °C/3.63 V (binding) | 24.81 µA | **24.80857 µA** | < 30 µA |
| enabled Iq, best corner | 10.06 µA | **10.05941 µA** | — |
| startup reached 1.764 V inside the enable window | 63/63 | **63/63** | — |

`iq_en_ua`, `iq_off_ua`, `ileak_vin_vout_ua` and `vout_off` agree with the
baseline record to every printed digit at all 63 corners (the extra digits
shown above are this record's native precision, not a change in value).
The run's own flag list reports `none` for every one of the nine checks it
prints, including `settled output outside +/-2% while enabled` and `limit
clamp engaged while settled at 50 mA` — the two this change could most
plausibly have broken if the `VREF` relocation had moved the DC operating
point.

`t_startup_us` agrees to six significant figures: 2295.46 µs (fastest
corner, `ff_125c_2.97v`) vs the baseline's 2295.46 µs, and 5771.05 µs
(slowest corner, `ss_-40c_3.63v`) vs the baseline's 5771.05 µs.

- **Overall (Enable/shutdown, ratified bounds): PASS** — unchanged from the
  baseline.
- **Overall (Iq, ratified < 30 µA at full load): PASS** — unchanged from the
  baseline.

This confirms DR-0021's evidence argument directly: relocating an ideal
voltage source from inside the `ldo_core` subcircuit to the deck that
instantiates it, on the same net with the same return, does not change the
DC operating point or the large-signal transient this bench measures.
