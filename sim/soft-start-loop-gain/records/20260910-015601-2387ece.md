- **Operating conditions**:
  - Load: the rated 50 mA point, in two load models -- a 36 ohm resistor
    (1.8 V / 50 mA, the model `sim/soft-start/` uses, and the only one that
    has a regulating solution low on the ramp) and an ideal 50 mA DC current
    sink (the model every `sim/loop-stability/` record uses; infinite
    small-signal impedance, the conservative choice). Which one a point used
    is in its `load_model` column.
  - Output cap: C_eff in {1uF, 4.7uF} with ESR in
    {0.001, 0.05, 0.1, 0.2, 0.5} ohm, in series, at the output pin.
    DERATED EFFECTIVE values per DR-0001. 1 uF / 100 mOhm is
    `sim/soft-start/`'s main-matrix output network; 4.7 uF / 1 mOhm and
    4.7 uF / 500 mOhm are its two 4.7 uF groups.
  - Enable state: enabled (EN = VIN), and therefore `HG` released --
    `Mhold_ss`/`Mhold_bg_ss` are in cutoff, so the pass gate belongs to the
    main loop. That is the hand-over state the #191 regression names. It is
    also what the real ramp does: `Rh_ss`/`Ch_ss` release `HG` with a time
    constant two orders of magnitude shorter than the ramp itself.
  - Ramp states (`V(SSR)` pinned by an ideal deck-level source through the
    promoted port, except in `anchor`):
  - **`ramp`** -- The ramp itself, with the rated load modelled as the 36 ohm resistor it physically is. Low on the ramp the regulated output is a fraction of a volt and an ideal sink demanding 50 mA from it has no solution on the regulating branch at all. States: `V(SSR) = 0 V` (a) ramp start, injection at full tilt; `V(SSR) = 0.05 V` (a1) the hold-release acquisition state -- `Rh_ss`/`Ch_ss` release `HG` with a ~150 us time constant and the #195 regression note times its glitch at ~300 us into the ramp, which at the ramp's own ~170 V/s is where V(SSR) is when the main loop takes the pass gate over; `V(SSR) = 0.15 V` (a1b) just above it, to bound how fast that state changes; `V(SSR) = 0.6 V` (a2) mid-ramp; `V(SSR) = 1.15 V` (b) VREF - 50 mV, just before the ideal element's hand-over; `V(SSR) = 1.25 V` (c) VREF + 50 mV, just after the ideal element's hand-over.
  - **`sink`** -- The hand-over points under sim/loop-stability's own load model (ideal DC current sink, infinite small-signal impedance -- the conservative choice), so these margins are directly comparable with its records. 1.8 V is added here because it is where the device-level chain's injection has actually decayed away (see the DC transfer in the record); 1.25 V is where the ideal source's has. States: `V(SSR) = 1.15 V` (b) VREF - 50 mV, just before the ideal element's hand-over; `V(SSR) = 1.25 V` (c) VREF + 50 mV, just after the ideal element's hand-over; `V(SSR) = 1.8 V` (d) VREF + 600 mV, past the device-level chain's own hand-over.
  - **`anchor`** -- The settled state: SSR is left free to sit where Mtop_ss's ceiling clamp puts it, which is exactly what sim/loop-stability's deck does, so this phase is that deck plus an unconnected port. SSR is not pinned in this phase.
  - Loop break: `ERRAMP_OUT` -> `PASS_GATE`, Tian/Middlebrook dual injection,
    exactly as `sim/loop-stability/testbench/tb_loop_stability.spice.in` does
    it -- so the reported loop gain is exact regardless of the source/load
    impedance ratio at the break and the DC operating point is the true
    closed-loop one.

- **Result**:

  **Swapping the ideal injection source for the device-level chain moves the phase margin by up to 20.84 deg** at the same pinned ramp state, which is above the ~2 deg cross-invocation movement class #182/#185 established. Read that number with section 1 in hand: at a fixed V(SSR) the two elements do **not** put the loop at the same operating point, because they do not inject the same current, so most of this delta is the loop being measured at a different output voltage (and therefore a different pass-device transconductance) rather than the injection element loading the loop differently. Separately, and more directly: at the worst measured point, AC-opening the device chain's own output drain from the feedback node -- which removes its entire small-signal loading while leaving the DC operating point bit-identical -- moves the phase margin by **+0.053 deg**. That is the injection element's small-signal cost with the operating-point shift held out of it, and it is below the ~2 deg cross-invocation movement class #182/#185 established.

  **How much capacitance the feedback node actually tolerates.**

  injection element has to stay under, and is what tests the
  hypothesis as stated. Every rung is a capacitor, so every rung is
  an open at DC and the landed `VOUT` column is there to show the
  bias point did not move.

  10 dB reference lines. A mid-ramp state is not a
  DR-0001 operating point, so those bars are reference lines here
  and not a criterion; and the worst-point ladder below starts from a baseline of 30.83 deg with no added capacitance at all -- already under the 45 deg line, with *either* injection element, because that corner is `sim/loop-stability/`'s own open 1-50 mA gap (#51).
