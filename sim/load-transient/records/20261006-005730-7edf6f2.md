Update (#325, 2026-09-24, carrying #304's measurement across from sim/psrr-vs-freq): the 'deletes' sentence above is scoped deliberately -- the compliance bound deletes the SINK-SUSTAINED sub-ground root and nothing else. Below the knee the sink is exactly 0 A and 0 S (f(VOUT) underflows to 0.0 in IEEE double for every VOUT <= -0.7530773732699249 V), so the load network is absent from the DC equations there: a sub-ground output voltage reported together with ZERO delivered current is outside the bound's reach by construction, and no knee or softness value can delete it because the sink has no term left in the equations to remove. That is why the pair of checks matters rather than either one alone: vout_min_global_v and iload_plateau_ma / iload_err_max_ua read the same run, and together they discriminate the cases -- a sub-ground reading alongside the COMMANDED current is the sink-sustained root the bound deletes, alongside ZERO delivered current it is a state the bound was never in a position to delete. The deck is deliberately unchanged on that account: #304 measured that knee tuning is coin-flipping (a strictly LOOSER bound 'fixes' the same corner, so the knee is not the mechanism) and that a load-side sub-ground clamp is worse still (it adds a genuine root at VOUT = -0.4994 V that a cold start reaches). See sim/harness/README.md, 'What the bound cannot reach', for the evidence and for the reltol-ladder recipe that tells a false convergence from a genuine second root.
